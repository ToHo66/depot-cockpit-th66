# Depot-Cockpit Version 5.1 – Kursdaten-Diagnose

Diese Version führt keinen automatischen Massenabruf aus.

Direkt auf der Übersicht gibt es den sichtbaren Button **Systemprüfung starten**.
Die Prüfung zeigt:
- Erreichbarkeit der Vercel-Funktion
- Vorhandensein des EODHD-Schlüssels
- getestetes Symbol und Handelsplatz
- HTTP-Status von EODHD
- Antwortzeit und Anzahl gelieferter Datensätze

Der normale Aktualisieren-Button besitzt zusätzlich einen festen 20-Sekunden-Abbruch und zeigt immer ein sichtbares Ergebnis.
